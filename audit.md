### The five systemic themes (fix these patterns, not just instances)

1. **Throwing stdlib under `-fno-exceptions`.** 15 call sites of `std::stoi/stoul/stol/stof/stoull` reachable from web-controlled input compile to `std::terminate` â€” any malformed URL host, CSS value, cache header, or an `<a href="about:settings?zoom=x">` link kills the process.
2. **Unbounded recursion over attacker-shaped trees.** Zero depth caps anywhere: DOM destruction/traversal, JS GC marking, JS parser nesting, JSON.parse, CSS `:not()`/`@media` parsing/matching, TrueType composite glyphs. One hostile page/file = stack overflow = process death.
3. **Mutable global state contradicting the stated principle.** `g_form_state` (keyed by raw pointers that get recycled â€” cross-document data bleed), canvas registry, timer/console/error statics, theme, tracker-blocker static, allocation counters â€” several read/written from pool threads without synchronization.
4. **String round-trips where structured values belong.** CSS values serializeâ†’re-parse between parse/cascade/layout (breaking `clamp()`, nested calc, `%` font-size); grid layout re-serializes style values to feed its own string parser; animation shorthand heuristics mangle names.
5. **Per-frame churn defeating caching.** Fresh `PaintExecutor` per frame (all texture caches discarded â†’ every image re-uploaded to VRAM 60Ã—/s), canvas pixel buffers copied into display lists per frame, fresh FBO per filtered element per frame, atlas pages leaked forever, full relayout for any change.

### Top 10 fixes if ordered strictly by impact

1. Wire up + harden TLS cert validation (`net/tls/handshake.cpp`, `net/tls/cert_verify.cpp`) â€” currently any MITM owns all HTTPS traffic.
2. Fix the four JS GC-rooting holes (`js/vm/vm.cpp:37`, timers, promise forwarding, XHR handlers).
3. Image decoder memory safety (JPEG chroma overflow, PNG zlib header fabrication, BMP/JPEG/PNG bounds).
4. Replace all throwing `std::sto*` calls with `from_chars`-based `Result` parsers (~6 files).
5. Add depth/nesting caps + iterative traversal/GC-marking/destruction everywhere (DoS class).
6. Fix the IOCP lost-wakeup race (`net/socket/tcp.cpp:430-466`) â€” intermittent permanent hangs.
7. Fix HTTP response truncation over TLS (>64KB bodies silently cut) + TLS record chunking.
8. Make native builtins able to invoke bytecode functions (`[1,2].map(f)` etc. are silent no-ops) and wire up prototypes.
9. Canvas dimension overflow (`w*h*4` in u32) + `getImageData` overflow â†’ heap corruption.
10. Persist `PaintExecutor` (or move its caches behind `Renderer`) to stop per-frame VRAM re-uploads.

### Performance

- JPEG IDCT computes `std::cos` per coefficient (`:137-147`): ~900 transcendental evaluations per 8Ã—8 block, two passes Ã— 56 cos calls each. Precompute 8Ã—8 cosine basis once (or AAN/Arai float IDCT) â†’ order-of-magnitude win on image-heavy pages.
